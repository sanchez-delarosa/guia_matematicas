Capítulo 43

Métodos de integración

UNAM IPN

Cuando una integral no coincide directamente con una fórmula inmediata, es necesario transformar el integrando.

Los métodos principales son:

  • sustitución o cambio de variable;
  • integración por partes;
  • sustitución trigonométrica;
  • fracciones parciales.

Antes de elegir un método, conviene simplificar el integrando, factorizar cuando sea posible e identificar su estructura.

43.1 ¿Qué método conviene utilizar?#

Estructura del integrandoMétodo sugerido
Función compuesta y aparece su derivadaSustitución
Producto de funciones de distinto tipoIntegración por partes
Radical con \(a^2-x^2\), \(a^2+x^2\) o \(x^2-a^2\)Sustitución trigonométrica
Cociente de polinomiosFracciones parciales
Advertencia

La tabla anterior es una guía, no una regla absoluta.

Antes de aplicar un método, revisa si la integral puede resolverse mediante una simplificación algebraica o una fórmula inmediata.

43.2 Integración por sustitución#

La sustitución se utiliza cuando aparece una función compuesta junto con la derivada de su parte interior.

Si:

\[u=g(x),\]

entonces:

\[du=g'(x)\,dx.\]

La transformación básica es:

\[\int f(g(x))g'(x)\,dx = \int f(u)\,du.\]

Procedimiento#

  1. Elige: \[u=g(x).\]
  2. Calcula: \[du=g'(x)\,dx.\]
  3. Reescribe toda la integral en términos de \(u\).
  4. Integra respecto de \(u\).
  5. Regresa a la variable original.
Ejemplo 43.1

Calcula:

\[\int(2x+1)^5\,dx.\]
Ver solución

Elegimos:

\[u=2x+1.\]

Entonces:

\[du=2\,dx,\]

por lo que:

\[dx=\frac{du}{2}.\]

Sustituimos:

\[\int(2x+1)^5\,dx = \frac12\int u^5\,du.\]

Integramos:

\[\frac12\left(\frac{u^6}{6}\right)+C = \frac{u^6}{12}+C.\]

Regresamos a \(x\):

\[\int(2x+1)^5\,dx = \frac{(2x+1)^6}{12}+C.\]
Ejemplo 43.2

Calcula:

\[\int2x\cos(x^2)\,dx.\]
Ver solución

Elegimos:

\[u=x^2.\]

Entonces:

\[du=2x\,dx.\]

La integral se transforma en:

\[\int\cos u\,du.\]

Integramos:

\[\sen u+C.\]

Por tanto:

\[\int2x\cos(x^2)\,dx = \sen(x^2)+C.\]
Ejemplo 43.3

Calcula:

\[\int\frac{dx}{3x+2}.\]
Ver solución

Elegimos:

\[u=3x+2.\]

Entonces:

\[du=3\,dx,\]

y:

\[dx=\frac{du}{3}.\]

Sustituimos:

\[\int\frac{dx}{3x+2} = \frac13\int\frac{du}{u}.\]

Por tanto:

\[\int\frac{dx}{3x+2} = \frac13\ln|3x+2|+C.\]
Ejemplo 43.4

Calcula:

\[\int xe^{x^2}\,dx.\]
Ver solución

Elegimos:

\[u=x^2.\]

Entonces:

\[du=2x\,dx,\]

por lo que:

\[x\,dx=\frac{du}{2}.\]

Sustituimos:

\[\int xe^{x^2}\,dx = \frac12\int e^u\,du.\]

Por tanto:

\[\int xe^{x^2}\,dx = \frac12e^{x^2}+C.\]
Nota

Si la derivada de la expresión elegida no aparece exactamente, puede ajustarse mediante un factor constante.

Por ejemplo:

\[\int x\cos(x^2)\,dx = \frac12\int2x\cos(x^2)\,dx.\]
Advertencia

En una integral indefinida, la respuesta final debe escribirse en la variable original.

No debe quedar la variable \(u\) en el resultado final.

43.2.1 Sustitución en integrales definidas#

En una integral definida pueden transformarse también los límites de integración.

Si:

\[u=g(x),\]

los nuevos límites se obtienen evaluando:

\[u_a=g(a)\]

y:

\[u_b=g(b).\]
Ejemplo 43.5

Calcula:

\[\int_0^1 2x(x^2+1)^3\,dx.\]
Ver solución

Elegimos:

\[u=x^2+1.\]

Entonces:

\[du=2x\,dx.\]

Transformamos los límites:

\[x=0 \quad\Longrightarrow\quad u=1,\]
\[x=1 \quad\Longrightarrow\quad u=2.\]

Por tanto:

\[\int_0^1 2x(x^2+1)^3\,dx = \int_1^2 u^3\,du.\]

Integramos:

\[\left[ \frac{u^4}{4} \right]_1^2.\]
\[= \frac{2^4}{4} - \frac{1^4}{4}.\]
\[= 4-\frac14.\]

Por tanto:

\[\int_0^1 2x(x^2+1)^3\,dx = \frac{15}{4}.\]
Nota

Si se cambian los límites de integración, no es necesario regresar a la variable \(x\).

También puede conservarse la variable original y evaluar después de deshacer la sustitución, pero no deben mezclarse ambos procedimientos.

43.3 Integración por partes#

La integración por partes se utiliza principalmente en productos de funciones de distinto tipo.

La fórmula es:

\[\int u\,dv = uv-\int v\,du.\]

Elección de \(u\)#

Una guía útil es el orden LIATE:

  1. L: funciones logarítmicas;
  2. I: funciones trigonométricas inversas;
  3. A: funciones algebraicas;
  4. T: funciones trigonométricas;
  5. E: funciones exponenciales.

Se elige como \(u\) la función que aparece primero en esta lista.

Se eligeOperación
\(u\)Se deriva para obtener \(du\)
\(dv\)Se integra para obtener \(v\)
Ejemplo 43.6

Calcula:

\[\int xe^x\,dx.\]
Ver solución

Elegimos:

\[u=x, \qquad dv=e^x\,dx.\]

Entonces:

\[du=dx, \qquad v=e^x.\]

Aplicamos la fórmula:

\[\int xe^x\,dx = xe^x-\int e^x\,dx.\]

Por tanto:

\[\int xe^x\,dx = xe^x-e^x+C.\]

También puede escribirse:

\[\int xe^x\,dx = e^x(x-1)+C.\]
Ejemplo 43.7

Calcula:

\[\int x\cos x\,dx.\]
Ver solución

Elegimos:

\[u=x, \qquad dv=\cos x\,dx.\]

Entonces:

\[du=dx, \qquad v=\sen x.\]

Aplicamos la fórmula:

\[\int x\cos x\,dx = x\sen x-\int\sen x\,dx.\]

Como:

\[\int\sen x\,dx = -\cos x,\]

se obtiene:

\[\int x\cos x\,dx = x\sen x+\cos x+C.\]
Ejemplo 43.8

Calcula:

\[\int\ln x\,dx.\]
Ver solución

Escribimos:

\[\int\ln x\cdot1\,dx.\]

Elegimos:

\[u=\ln x, \qquad dv=dx.\]

Entonces:

\[du=\frac{1}{x}\,dx, \qquad v=x.\]

Aplicamos la fórmula:

\[\int\ln x\,dx = x\ln x - \int x\left(\frac1x\right)dx.\]
\[= x\ln x-\int1\,dx.\]

Por tanto:

\[\int\ln x\,dx = x\ln x-x+C.\]
Ejemplo 43.9

Calcula:

\[\int x^2e^x\,dx.\]
Ver solución

Elegimos:

\[u=x^2, \qquad dv=e^x\,dx.\]

Entonces:

\[du=2x\,dx, \qquad v=e^x.\]

Aplicamos la fórmula:

\[\int x^2e^x\,dx = x^2e^x - 2\int xe^x\,dx.\]

Del ejemplo anterior:

\[\int xe^x\,dx = e^x(x-1).\]

Sustituimos:

\[\int x^2e^x\,dx = x^2e^x - 2e^x(x-1)+C.\]

Factorizamos:

\[\int x^2e^x\,dx = e^x(x^2-2x+2)+C.\]
Advertencia

La fórmula contiene una resta:

\[\int u\,dv = uv-\int v\,du.\]

Un error frecuente es olvidar el signo negativo.

43.4 Sustitución o integración por partes#

Conviene utilizar sustitución cuando aparece una función y la derivada de su parte interior:

\[\int2x\cos(x^2)\,dx.\]

Conviene utilizar integración por partes cuando aparece un producto como:

\[\int xe^x\,dx\]

o:

\[\int x\cos x\,dx.\]
IntegralPatrónMétodo
\(\displaystyle\int2x\cos(x^2)\,dx\)Función compuestaSustitución
\(\displaystyle\int xe^x\,dx\)Producto de tipos distintosPor partes
\(\displaystyle\int\frac{2x}{x^2+1}\,dx\)Interior y derivadaSustitución
\(\displaystyle\int x\ln x\,dx\)Producto con logaritmoPor partes

43.5 Sustitución trigonométrica#

IPN

La sustitución trigonométrica se utiliza principalmente cuando aparecen radicales con expresiones cuadráticas.

ExpresiónSustituciónIdentidad
\(\sqrt{a^2-x^2}\)\(x=a\sen\theta\)\(1-\sen^2\theta=\cos^2\theta\)
\(\sqrt{a^2+x^2}\)\(x=a\tan\theta\)\(1+\tan^2\theta=\sec^2\theta\)
\(\sqrt{x^2-a^2}\)\(x=a\sec\theta\)\(\sec^2\theta-1=\tan^2\theta\)

Procedimiento#

  1. Identifica el patrón del radical.
  2. Elige la sustitución correspondiente.
  3. Calcula \(dx\).
  4. Simplifica mediante una identidad trigonométrica.
  5. Integra respecto de \(\theta\).
  6. Regresa a la variable \(x\).
Ejemplo 43.10

IPN

Calcula:

\[\int\frac{dx}{\sqrt{4-x^2}}.\]
Ver solución

La expresión tiene la forma:

\[\sqrt{a^2-x^2}\]

con:

\[a=2.\]

Elegimos:

\[x=2\sen\theta.\]

Entonces:

\[dx=2\cos\theta\,d\theta.\]

Además:

\[\sqrt{4-x^2} = \sqrt{4-4\sen^2\theta}.\]
\[= 2\sqrt{1-\sen^2\theta}.\]

En el intervalo adecuado:

\[\sqrt{4-x^2} = 2\cos\theta.\]

Sustituimos:

\[\int \frac{2\cos\theta\,d\theta} {2\cos\theta} = \int d\theta.\]

Por tanto:

\[\theta+C.\]

Como:

\[x=2\sen\theta,\]

se obtiene:

\[\theta = \arcsen\left(\frac{x}{2}\right).\]

Finalmente:

\[\int\frac{dx}{\sqrt{4-x^2}} = \arcsen\left(\frac{x}{2}\right)+C.\]
Ejemplo 43.11

IPN

Calcula:

\[\int\frac{dx}{x^2+1}.\]
Ver solución

Elegimos:

\[x=\tan\theta.\]

Entonces:

\[dx=\sec^2\theta\,d\theta.\]

Además:

\[x^2+1 = \tan^2\theta+1 = \sec^2\theta.\]

Sustituimos:

\[\int \frac{\sec^2\theta\,d\theta} {\sec^2\theta} = \int d\theta.\]

Por tanto:

\[\theta+C.\]

Como:

\[x=\tan\theta,\]

se tiene:

\[\theta=\arctan x.\]

Finalmente:

\[\int\frac{dx}{x^2+1} = \arctan x+C.\]
Nota

La integral anterior también puede reconocerse como una fórmula inmediata:

\[\int\frac{dx}{1+x^2} = \arctan x+C.\]

La sustitución trigonométrica explica el origen de esta fórmula.

43.6 Fracciones parciales#

IPN

Las fracciones parciales se utilizan para integrar funciones racionales:

\[\frac{P(x)}{Q(x)}.\]

Primero debe cumplirse:

\[\deg P<\deg Q.\]

Si:

\[\deg P\geq\deg Q,\]

debe realizarse primero la división de polinomios.

43.6.1 Formas de descomposición#

Factores lineales distintos#

Si:

\[Q(x)=(x-a)(x-b),\]

se plantea:

\[\frac{P(x)}{Q(x)} = \frac{A}{x-a} + \frac{B}{x-b}.\]

Factor lineal repetido#

Si aparece:

\[(x-a)^n,\]

se incluyen todos los términos:

\[\frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \cdots + \frac{A_n}{(x-a)^n}.\]

Factor cuadrático irreducible#

Si aparece un factor:

\[ax^2+bx+c\]

que no puede factorizarse en números reales, se utiliza:

\[\frac{Ax+B}{ax^2+bx+c}.\]

Procedimiento#

  1. Verifica que la fracción sea propia.
  2. Factoriza el denominador.
  3. Plantea la descomposición.
  4. Multiplica por el denominador común.
  5. Encuentra las constantes.
  6. Integra cada fracción.
Ejemplo 43.12

IPN

Calcula:

\[\int\frac{dx}{x^2-1}.\]
Ver solución

Factorizamos:

\[x^2-1 = (x-1)(x+1).\]

Planteamos:

\[\frac{1}{(x-1)(x+1)} = \frac{A}{x-1} + \frac{B}{x+1}.\]

Multiplicamos por:

\[(x-1)(x+1).\]

Obtenemos:

\[1 = A(x+1)+B(x-1).\]

Si:

\[x=1,\]

entonces:

\[1=2A,\]

por lo que:

\[A=\frac12.\]

Si:

\[x=-1,\]

entonces:

\[1=-2B,\]

por lo que:

\[B=-\frac12.\]

Así:

\[\frac{1}{x^2-1} = \frac{1}{2(x-1)} - \frac{1}{2(x+1)}.\]

Integramos:

\[\int\frac{dx}{x^2-1} = \frac12\ln|x-1| - \frac12\ln|x+1| + C.\]

También puede escribirse:

\[\int\frac{dx}{x^2-1} = \frac12 \ln\left| \frac{x-1}{x+1} \right| +C.\]
Ejemplo 43.13

IPN

Calcula:

\[\int \frac{3x+5}{x^2+3x+2}\,dx.\]
Ver solución

Factorizamos:

\[x^2+3x+2 = (x+1)(x+2).\]

Planteamos:

\[\frac{3x+5}{(x+1)(x+2)} = \frac{A}{x+1} + \frac{B}{x+2}.\]

Multiplicamos por el denominador común:

\[3x+5 = A(x+2)+B(x+1).\]

Si:

\[x=-1,\]

entonces:

\[2=A.\]

Si:

\[x=-2,\]

entonces:

\[-1=-B,\]

por lo que:

\[B=1.\]

Así:

\[\frac{3x+5}{x^2+3x+2} = \frac{2}{x+1} + \frac{1}{x+2}.\]

Integramos:

\[\int \frac{3x+5}{x^2+3x+2}\,dx = 2\ln|x+1| + \ln|x+2| + C.\]
Advertencia

Si un factor lineal está repetido, deben incluirse todas sus potencias.

Por ejemplo, para:

\[(x-1)^3,\]

deben aparecer:

\[\frac{A}{x-1} + \frac{B}{(x-1)^2} + \frac{C}{(x-1)^3}.\]

43.7 Verificación del resultado#

Toda integral indefinida puede comprobarse derivando el resultado.

Ejemplo 43.14

Comprueba:

\[\int xe^x\,dx = e^x(x-1)+C.\]
Ver solución

Derivamos mediante la regla del producto:

\[\frac{d}{dx} \left[ e^x(x-1) \right] = e^x(x-1)+e^x.\]

Simplificamos:

\[e^x(x-1+1) = xe^x.\]

La derivada coincide con el integrando, por lo que el resultado es correcto.

43.8 Procedimiento rápido#

Antes de integrar:

  1. simplifica el integrando;
  2. factoriza si es posible;
  3. revisa si corresponde a una fórmula inmediata;
  4. identifica la estructura principal;
  5. elige el método más conveniente;
  6. agrega \(C\) si la integral es indefinida;
  7. comprueba derivando.
PreguntaDecisión
¿Aparece una función y su derivada?Sustitución
¿Es un producto de funciones de distinto tipo?Por partes
¿Hay un radical cuadrático especial?Sustitución trigonométrica
¿Es un cociente de polinomios?Fracciones parciales

43.9 Resumen#

Sustitución:

\[u=g(x), \qquad du=g'(x)\,dx.\]
\[\int f(g(x))g'(x)\,dx = \int f(u)\,du.\]

Integración por partes:

\[\int u\,dv = uv-\int v\,du.\]

Sustituciones trigonométricas:

\[\sqrt{a^2-x^2} \quad\Longrightarrow\quad x=a\sen\theta,\]
\[\sqrt{a^2+x^2} \quad\Longrightarrow\quad x=a\tan\theta,\]
\[\sqrt{x^2-a^2} \quad\Longrightarrow\quad x=a\sec\theta.\]

Fracciones parciales:

\[\frac{P(x)}{Q(x)} = \text{suma de fracciones simples}.\]

43.10 Errores frecuentes#

Advertencia

Recuerda:

  • En sustitución, toda la integral debe escribirse en la nueva variable.
  • La respuesta final de una integral indefinida no debe conservar la variable \(u\).
  • En integración por partes aparece una resta: \[uv-\int v\,du.\]
  • La elección de \(u\) debe simplificar la integral.
  • En una integral definida, si se transforman los límites, no debe evaluarse después con los límites originales.
  • En fracciones parciales, la fracción debe ser propia.
  • El denominador debe factorizarse antes de plantear la descomposición.
  • Los factores repetidos requieren términos para todas sus potencias.
  • Un factor cuadrático irreducible requiere un numerador lineal: \[Ax+B.\]
  • Toda integral indefinida debe incluir: \[+C.\]
  • El resultado puede comprobarse derivando.

43.11 Ejercicios propuestos#

Ejercicio 43.1

Calcula por sustitución:

\[\int(3x-2)^4\,dx.\]
Ver solución

Con \(u = 3x - 2\), \(du = 3\, dx\): \[\int u^4 \cdot \frac{du}{3} = \frac{u^5}{15} + C = \frac{(3x - 2)^5}{15} + C.\]

Ejercicio 43.2

Calcula por sustitución:

\[\int\sen(5x)\,dx.\]
Ver solución

Con \(u = 5x\), \(du = 5\, dx\): \[\int \sen u \cdot \frac{du}{5} = -\frac{\cos u}{5} + C = -\frac{\cos(5x)}{5} + C.\]

Ejercicio 43.3

Calcula por sustitución:

\[\int xe^{3x^2}\,dx.\]
Ver solución

Con \(u = 3x^2\), \(du = 6x\, dx\): \[\int e^u \cdot \frac{du}{6} = \frac{e^u}{6} + C = \frac{e^{3x^2}}{6} + C.\]

Ejercicio 43.4

Calcula por sustitución:

\[\int\frac{4x}{2x^2+3}\,dx.\]
Ver solución

Con \(u = 2x^2 + 3\), \(du = 4x\, dx\): \[\int \frac{du}{u} = \ln|u| + C = \ln(2x^2 + 3) + C.\]

Ejercicio 43.5

Calcula por partes:

\[\int x\sen x\,dx.\]
Ver solución

\(u = x\), \(dv = \sen x\, dx\), \(du = dx\), \(v = -\cos x\): \[\int x \sen x\, dx = -x\cos x + \int \cos x\, dx = -x\cos x + \sen x + C.\]

Ejercicio 43.6

Calcula por partes:

\[\int x\ln x\,dx.\]
Ver solución

\(u = \ln x\), \(dv = x\, dx\), \(du = \frac{dx}{x}\), \(v = \frac{x^2}{2}\): \[\int x \ln x\, dx = \frac{x^2}{2}\ln x - \int \frac{x^2}{2}\cdot\frac{dx}{x} = \frac{x^2}{2}\ln x - \frac{1}{2}\int x\, dx = \frac{x^2}{2}\ln x - \frac{x^2}{4} + C.\]

Ejercicio 43.7

Calcula por partes:

\[\int x^2\cos x\,dx.\]
Ver solución

\(u = x^2\), \(dv = \cos x\, dx\), \(du = 2x\, dx\), \(v = \sen x\): \[\int x^2 \cos x\, dx = x^2 \sen x - 2 \int x \sen x\, dx.\] Del ejercicio 43.5, sabemos que \(\int x \sen x\, dx = -x\cos x + \sen x\). Así: \[= x^2 \sen x - 2(-x\cos x + \sen x) + C = x^2 \sen x + 2x \cos x - 2 \sen x + C.\]

Ejercicio 43.8

Calcula:

\[\int_0^1 2x(x^2+2)^2\,dx.\]
Ver solución

Con \(u = x^2 + 2\), \(du = 2x\, dx\). Los límites cambian: si \(x=0\), \(u=2\); si \(x=1\), \(u=3\). \[\int_2^3 u^2\, du = \left[ \frac{u^3}{3} \right]_2^3 = \frac{3^3}{3} - \frac{2^3}{3} = 9 - \frac{8}{3} = \frac{19}{3}.\]

Ejercicio 43.9

IPN

Calcula mediante sustitución trigonométrica:

\[\int\frac{dx}{\sqrt{9-x^2}}.\]
Ver solución

Tiene la forma \(\sqrt{a^2 - x^2}\) con \(a=3\). \[\int \frac{dx}{\sqrt{9 - x^2}} = \arcsen\!\left(\frac{x}{3}\right) + C.\]

Ejercicio 43.10

IPN

Calcula mediante sustitución trigonométrica:

\[\int\frac{dx}{x^2+4}.\]
Ver solución

Tiene la forma \(x^2 + a^2\) con \(a=2\). \[\int \frac{dx}{x^2 + 4} = \frac{1}{2}\arctan\!\left(\frac{x}{2}\right) + C.\]

Ejercicio 43.11

IPN

Calcula mediante fracciones parciales:

\[\int\frac{dx}{x^2-4}.\]
Ver solución

\(x^2 - 4 = (x - 2)(x + 2)\). \[\frac{1}{(x - 2)(x + 2)} = \frac{A}{x - 2} + \frac{B}{x + 2}.\] \(1 = A(x + 2) + B(x - 2)\). En \(x = 2\): \(A = \frac{1}{4}\). En \(x = -2\): \(B = -\frac{1}{4}\). \[\int \frac{dx}{x^2 - 4} = \frac{1}{4}\ln|x - 2| - \frac{1}{4}\ln|x + 2| + C = \frac{1}{4}\ln\left|\frac{x - 2}{x + 2}\right| + C.\]

Ejercicio 43.12

IPN

Calcula mediante fracciones parciales:

\[\int \frac{2x+1}{(x-1)(x+2)}\,dx.\]
Ver solución

\[\frac{2x + 1}{(x - 1)(x + 2)} = \frac{A}{x - 1} + \frac{B}{x + 2}.\] \(2x + 1 = A(x + 2) + B(x - 1)\). En \(x = 1\): \(3 = 3A \Rightarrow A = 1\). En \(x = -2\): \(-3 = -3B \Rightarrow B = 1\). \[\int \frac{2x + 1}{(x - 1)(x + 2)}\, dx = \ln|x - 1| + \ln|x + 2| + C = \ln|(x - 1)(x + 2)| + C.\]

Ejercicio 43.13

IPN

Calcula mediante fracciones parciales:

\[\int \frac{5x+3}{x^2+x-2}\,dx.\]
Ver solución

\(x^2 + x - 2 = (x + 2)(x - 1)\). \[\frac{5x + 3}{(x - 1)(x + 2)} = \frac{A}{x - 1} + \frac{B}{x + 2}.\] \(5x + 3 = A(x + 2) + B(x - 1)\). En \(x = 1\): \(8 = 3A \Rightarrow A = \frac{8}{3}\). En \(x = -2\): \(-7 = -3B \Rightarrow B = \frac{7}{3}\). \[\int \frac{5x + 3}{x^2 + x - 2}\, dx = \frac{8}{3}\ln|x - 1| + \frac{7}{3}\ln|x + 2| + C.\]
